3.1Tipos primitivos

Cada dato de un programa tiene un tipo: el tipo dice qué valores puede guardar, qué se puede hacer con él y cómo se escribe. PseudoLearn tiene cinco tipos primitivos, y con ellos se construyen todos los demás.

3.1.1Un primer vistazo

Una variable se declara con Definir, su nombre, la palabra Como y su tipo. Desde ese momento, la variable solo acepta valores de ese tipo, y su tipo no cambia mientras el programa se ejecuta. Este programa usa los cinco:

La ficha de Lucía✓ Ejecutado con el motor
Proceso FichaDeLucia
  Definir edad Como Entero <- 11;
  Definir altura Como Real <- 1.42;
  Definir inicial Como Caracter <- 'L';
  Definir nombre Como Cadena <- "Lucía";
  Definir aprobada Como Logico <- Verdadero;
  Escribir nombre + " (" + inicial + ")";
  Escribir edad, " años, ", altura, " m";
  Escribir aprobada;
FinProceso
Salidaterminación: completed
Lucía (L)
11 años, 1.42 m
Verdadero
TipoQué guardaCómo se escribe un valor

Analogía

Piensa en el tipo como la forma de un recipiente: en una huevera caben huevos y en una botella cabe líquido. No puedes guardar sopa en la huevera aunque las dos sirvan «para guardar». La analogía deja de valer en un punto: algunos valores sí pasan solos de un recipiente a otro, siempre que no se pierda nada (3.1.7).

3.1.2Entero

Un Entero es un número sin parte decimal. Se escribe solo con cifras: 2026. El signo menos no forma parte del número; es una operación que se aplica después, así que -7 significa «el opuesto de 7».

Las operaciones con enteros dan el resultado exacto, sin redondeos, mientras el resultado quepa en el rango. Hay tres formas de dividir, y conviene no confundirlas:

Tres maneras de dividir 7 entre 2✓ Ejecutado con el motor
Proceso Dividir
  Escribir 7 / 2, " ", 7 div 2, " ", 7 mod 2;
FinProceso
Salidaterminación: completed
3.5 3 1
7 / 2
Divide «de verdad» y siempre da un Real, aunque los dos números sean enteros.
7 div 2
Cociente entero: cuántas veces cabe el 2 en el 7. Recorta hacia el cero.
7 mod 2
Lo que sobra al repartir. Cumple siempre 7 = (7 div 2) * 2 + (7 mod 2).
Límite exacto

Un Entero ocupa 64 bits con signo. Su rango va desde -9223372036854775808 hasta 9223372036854775807, ambos incluidos.

Salirse del rango no da la vuelta en silencio: el programa se detiene con integerOverflow. Un literal positivo mayor que el máximo ya es un error antes de ejecutar (integerLiteralOutOfRange), aunque lleve un menos delante.

Pasarse del máximo✕ Falla al ejecutar
Proceso Desborde
  Definir grande Como Entero <- 9223372036854775807;
  Escribir grande + 1;
FinProceso
errorLa operación produce un entero fuera del rango de 64 bits con signo
integerOverflowlínea 3, columna 19
No se escribe nada: la suma no llega a producir un valor. Si necesitas números así de grandes, revisa el cálculo; si son medidas aproximadas, usa Real.

3.1.3Real

Un Real es un número con parte decimal. Se escribe con un punto y al menos una cifra a cada lado: 0.5 es válido, .5 y 5. no lo son. No existe la notación con exponente.

Al escribirlo, un real muestra siempre al menos un decimal, para que se distinga de un entero a simple vista:

Los reales siempre muestran su punto✓ Ejecutado con el motor
Proceso Precios
  Definir precio Como Real <- 7;
  Escribir precio;
  Escribir 0.1 + 0.2;
FinProceso
Salidaterminación: completed
7.0
0.30000000000000004

La segunda línea sorprende a casi todo el mundo. No es un fallo del motor: es cómo funcionan los reales en cualquier computadora moderna. La Figura 3.1-2 lo explica.

Por eso preguntar si dos reales son exactamente iguales casi nunca es buena idea. El motor lo permite, pero avisa:

Comparar reales con =⚠ Se ejecuta con aviso
Proceso Comparar
  Definir a Como Real <- 0.1 + 0.2;
  Si a = 0.3 Entonces
    Escribir "iguales";
  Sino
    Escribir "distintos";
  FinSi
FinProceso
Salidaterminación: completed
distintos
advertenciaComparación de igualdad entre valores reales; los errores de precisión pueden producir resultados inesperados
realEqualityComparisonlínea 3, columna 6
Compara la distancia: Abs(a - 0.3) < 0.000001 responde «están lo bastante cerca».
Límite exacto
  • Un Real es un número binario de coma flotante de 64 bits (IEEE 754 binario64), siempre finito.
  • Cada operación redondea al valor representable más cercano; en un empate, al de mantisa par.
  • No existen el infinito ni «no es un número»: una operación que los produciría se detiene con nonFiniteRealResult. Por ejemplo, exp(1000).
  • El mayor real es 1.7976931348623157 × 10³⁰⁸; existen 0.0 y -0.0.

3.1.4Logico

Un Logico tiene exactamente dos valores: Verdadero y Falso. Es el tipo de toda pregunta: edad >= 18 no es un número, es un Logico. Las condiciones de Si, Mientras y Repetir solo aceptan este tipo.

Tres cosas que un Logico no es:

  • No es un número. Verdadero + 1 es un error; no vale 1 ni 0.
  • No tiene orden. Preguntar si Verdadero > Falso no tiene sentido y el motor lo rechaza.
  • No se vuelve texto solo. Para unirlo a una cadena hay que pedirlo con ConvertirATexto. Al escribirlo, aparece con la palabra del perfil activo: Verdadero en español, true en inglés.
Los lógicos no se ordenan✕ No compila
Proceso Orden
  Escribir Verdadero > Falso;
FinProceso
errorLos operadores relacionales de orden no están permitidos entre valores lógicos
noOrderBetweenBooleanslínea 2, columna 12
Para comparar dos lógicos usa = o <>.

3.1.5Caracter

Un Caracter es un único símbolo: una letra, una cifra, un signo, un espacio o un emoji. Técnicamente es un valor escalar Unicode, es decir, un número que identifica a ese símbolo en la tabla universal de símbolos. CodigoDe da ese número y CaracterDesde hace el camino inverso.

Las comillas simples y dobles son equivalentes. Lo que decide el tipo de un literal es cuántos símbolos tiene dentro: exactamente uno es Caracter; ninguno o más de uno es Cadena.

LiteralSímbolos dentroTipo

"😀"1Caracter

Límite exacto

Un Caracter es cualquier punto de código Unicode entre 0 y 1114111, excepto los sustitutos 55296 a 57343. CaracterDesde(55296) se detiene con invalidCharacterCode.

3.1.6Cadena

Una Cadena es una fila de caracteres. Puede estar vacía ("") y no tiene un largo máximo fijado por el lenguaje. Las posiciones se cuentan desde cero, como en la Figura 3.1-1: en "Lucía", la 'L' está en la posición 0 y la 'a' en la 4.

Medir y mirar dentro de un texto✓ Ejecutado con el motor
Proceso Textos
  Escribir Longitud(""), " ", Longitud("año"), " ", CaracterEn("Hola", 0), " ", CodigoDe('A');
FinProceso
Salidaterminación: completed
0 3 H 65

El operador + une cadenas y caracteres en cualquier combinación, y el resultado es siempre una Cadena. Lo que + no hace es convertir un número en texto:

Un número no se pega a un texto✕ No compila
Proceso Mezcla
  Escribir "Tengo " + 11;
FinProceso
errorNo se puede concatenar un número con texto; use la función de conversión o separe las expresiones con coma
cannotConcatenateNumberWithTextlínea 2, columna 12
Dos arreglos posibles: Escribir "Tengo ", 11; o Escribir "Tengo " + ConvertirATexto(11);
Cuidado

Una Cadena cuenta puntos de código, no «letras que ves». La é puede escribirse como un único símbolo o como una e seguida de un acento que se le monta encima. Se ven iguales, pero la segunda forma mide 2. El motor no las unifica: respeta exactamente lo que escribiste.

3.1.7Pasar de un tipo a otro

El lenguaje solo convierte un valor por su cuenta cuando es imposible perder información. Todo lo demás hay que pedirlo con una función, porque la decisión de cómo convertir es de quien escribe el programa.

Conversiones pedidas✓ Ejecutado con el motor
Proceso Conversiones
  Definir nota Como Real <- -8.7;
  Escribir Trunc(nota), " ", Redon(nota), " ", ConvertirATexto(1.5) + "!";
FinProceso
Salidaterminación: completed
-8 -9 1.5!

Trunc corta los decimales (va hacia el cero) y Redon redondea al entero más cercano. Con -8.7 dan resultados distintos, y por eso el lenguaje no elige por ti:

Un real no entra solo en un entero✕ No compila
Proceso SinPerder
  Definir cantidad Como Entero <- 2.5;
FinProceso
errorTipo incompatible en la asignación: no se puede asignar Real a Entero
incompatibleTypesInAssignmentlínea 2, columna 3
Decide qué quieres: Trunc(2.5) da 2 y Redon(2.5) da 3.
Para docentes
  • «Un número entre comillas es un número». "7" es un Caracter; "75" es una Cadena. Pide a la clase que prediga el tipo antes de ejecutar.
  • «/ entre enteros da entero». En PseudoLearn siempre da real. El ejemplo de las tres divisiones es buen material de predicción.
  • «0.1 + 0.2 = 0.3». No lo presentes como una rareza del lenguaje: es una propiedad de cómo cualquier computadora guarda los decimales. La Figura 3.1-2 sirve para dibujarla en la pizarra.

3.1.8Por dentro

Cómo guarda el motor cada tipo

Antes de ejecutar, el motor traduce el programa a una representación intermedia (RI). Esta es la RI real de las declaraciones de La ficha de Lucía, obtenida con pseudo ri:

  stmt.enter @2:3-2:33
  %0 = const.i64 11 @2:31-2:33
  stmt.enter @3:3-3:35
  %1 = const.f64 1.42 @3:31-3:35
  stmt.enter @4:3-4:39
  %2 = const.char 'L' @4:36-4:39
  stmt.enter @5:3-5:40
  %3 = const.str "Lucía" @5:33-5:40
  stmt.enter @6:3-6:44
  %4 = const.bool true @6:35-6:44

Cada instrucción dice qué clase de valor produce: i64 (entero de 64 bits), f64 (real de 64 bits), char, str y bool. Como el tipo de cada registro ya se conoce al compilar, ningún valor lleva una etiqueta de tipo mientras el programa corre: la máquina virtual no pregunta «¿qué eres?» en cada paso.

Las conversiones automáticas son instrucciones

Cuando escribes Definir precio Como Real <- 7;, el analizador ve un Entero donde se espera un Real y añade él mismo la conversión. En la RI aparece de forma explícita:

  %0 = const.i64 7 @2:31-2:32
  %1 = int.to_real %0 @2:31-2:32

La conversión de Caracter a Cadena funciona igual, con la instrucción text.format. Ninguna conversión es mágica: si no aparece en la RI, no ocurre.

3.1.9En resumen

  • Hay cinco tipos primitivos: Entero, Real, Logico, Caracter y Cadena. El tipo de una variable no cambia nunca.
  • Un Entero es exacto dentro de su rango; salirse del rango detiene el programa, nunca da la vuelta en silencio.
  • Un Real guarda la marca más cercana de una regla finísima, siempre es finito y al escribirse muestra al menos un decimal.
  • Un Logico es Verdadero o Falso: no es un número y no tiene orden.
  • Un literal con un solo símbolo dentro es Caracter, con comillas simples o dobles; con cero o varios, es Cadena.
  • Una Cadena puede estar vacía, cuenta posiciones desde 0 y respeta exactamente los símbolos que escribiste.
  • Solo pasan solos de un tipo a otro Entero → Real y Caracter → Cadena. Todo lo demás se pide con una función.

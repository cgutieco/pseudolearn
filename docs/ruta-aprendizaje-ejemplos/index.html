Ruta de aprendizaje de PseudoLearn

Aprender a resolver problemas desde cero, con cinco formas de pensar un programa. Cada lección empieza con un problema, no con una palabra del lenguaje. Las tres lecciones resaltadas son muestras completas para evaluar tono, figuras, ejercicios y enlaces a la Especificación.

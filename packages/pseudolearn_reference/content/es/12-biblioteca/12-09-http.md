::: frase
Con la capacidad de red, un programa construye una petición HTTP, la envía y recibe una respuesta con su estado, sus cabeceras y su cuerpo.
:::

## Cómo funciona {#funciona}

1. `SolicitarRed()` da una `RedCap`.
2. `PeticionHttp(metodo, url)` crea una petición con un `MetodoHttp`: `GET`, `HEAD`, `POST`, `PUT`, `PATCH` o `DELETE`. Las peticiones son inmutables: `ConCabecera`, `ConCuerpoTexto` o `ConTiempoMaximo` devuelven una petición nueva.
3. `red.Enviar(peticion)` devuelve `Resultado<RespuestaHttp, ErrorES>`.

```figura id=http-ida-vuelta
pie: La petición sale por la capacidad de red y vuelve una respuesta. Un 404 o un 500 son respuestas, no errores: solo los fallos de transporte llegan como `ErrorES`.
```

```programa id=clima titulo="Pedir el tiempo que hace" ejecutar
SubProceso ConsultarClima() Como Resultado<Cadena, ErrorES>
  Definir red Como RedCap <- Propagar SolicitarRed();
  Definir peticion Como PeticionHttp <- PeticionHttp(MetodoHttp.GET, "https://clima.test/hoy");
  Definir respuesta Como RespuestaHttp <- Propagar red.Enviar(peticion);
  Escribir "Estado: ", respuesta.Estado();
  Retornar respuesta.CuerpoTexto();
FinSubProceso

Algoritmo Clima
  Segun ConsultarClima() Hacer
    Exito(texto): Escribir texto;
    Error(problema): Escribir problema.Codigo;
  FinSegun
FinAlgoritmo
```

```anfitrion
{"http": {"GET https://clima.test/hoy": {"estado": 200, "cuerpo": "Soleado, 25"}}}
```

```salida
Estado: 200
Soleado, 25
```

Una respuesta con estado de 100 a 599 es siempre `Exito`; `EsExito()` dice si está entre 200 y 299. Los métodos que pueden modificar el servidor —`POST`, `PUT`, `PATCH`, `DELETE`— pueden quedar en estado **incierto** si la conexión se corta a mitad: el programa no puede saber si el cambio se hizo.

::: limite
- Solo se admiten URL `http` o `https` con un host ASCII y sin credenciales.
- Las redirecciones no se siguen solas: `Redirigida` construye la petición siguiente.
- Los tamaños y plazos los limita el anfitrión; `ConLimiteRespuesta` y `ConTiempoMaximo` solo pueden reducirlos.
:::

::: resumen
- `SolicitarRed`, `PeticionHttp` y `Enviar`: capacidad, petición y respuesta.
- Los estados HTTP son respuestas; los fallos de red son `ErrorES`.
- Las peticiones son inmutables y los límites, del anfitrión.
:::

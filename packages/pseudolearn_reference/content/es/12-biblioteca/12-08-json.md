::: frase
`AnalizarJson` convierte un texto JSON en un valor que se puede recorrer, y `TextoJson` hace el camino de vuelta.
:::

## Cómo funciona {#funciona}

`AnalizarJson(texto)` devuelve un `Resultado`: `Exito` con un `ValorJson`, o `Error` con un `ErrorJson` que dice qué falló y dónde. Sobre un `ValorJson` se pregunta:

| Operación | Devuelve |
|---|---|
| `v.Tipo()` | qué clase de valor es: objeto, arreglo, texto, número, lógico o nulo |
| `v.Campo(clave)` | `Algo(valor)` o `Nada` |
| `v.Elemento(i)` | `Algo(valor)` o `Nada`, con índices desde cero |
| `v.Claves()`, `v.Longitud()` | las claves en su orden original; cuántos elementos |
| `ComoEntero`, `ComoReal`, `ComoCadena`, `ComoLogico` | `Algo` si el valor es de ese tipo |

```figura id=json-arbol
pie: El texto JSON y el árbol de valores que produce `AnalizarJson`. `Campo` y `Elemento` bajan por el árbol.
```

```programa id=ficha-json titulo="Leer una ficha" ejecutar
Algoritmo Ficha
  Segun AnalizarJson('{"nombre": "Ana", "edad": 15, "notas": [7, 9]}') Hacer
    Exito(ficha):
      Escribir ficha.Claves(), " ", ficha.Longitud();
      Segun ficha.Campo("edad") Hacer
        Algo(edad): Escribir "edad: ", TextoJson(edad);
        Nada: Escribir "sin edad";
      FinSegun
      Escribir TextoJson(ficha);
    Error(problema):
      Escribir problema.Codigo;
  FinSegun
FinAlgoritmo
```

```salida
["nombre", "edad", "notas"] 3
edad: 15
{"nombre":"Ana","edad":15,"notas":[7,9]}
```

`TextoJson` escribe JSON compacto, conserva el orden de las claves y el texto original de los números. Analizar lo que escribe devuelve el mismo valor.

El análisis es **estricto**: sin comentarios, sin comas finales, sin claves repetidas. El error dice la línea y la columna donde se detectó:

```programa id=json-roto titulo="Una coma de más" ejecutar
Algoritmo Roto
  Segun AnalizarJson('{"edad": 15,}') Hacer
    Exito(ficha): Escribir TextoJson(ficha);
    Error(problema):
      Definir codigo Como CodigoErrorJson <- problema.Codigo;
      Escribir codigo, " en ", problema.JsonLinea, ":", problema.JsonColumna;
  FinSegun
FinAlgoritmo
```

```salida
SintaxisInvalida en 1:13
```

Los valores de `TipoJson` y de `CodigoErrorJson` son estos:

| `TipoJson` | `CodigoErrorJson` |
|---|---|
| `TipoJson.Objeto`, `TipoJson.Arreglo` | `CodigoErrorJson.SintaxisInvalida` |
| `TipoJson.CadenaJson`, `TipoJson.JsonNumero` | `CodigoErrorJson.FinInesperado`, `CodigoErrorJson.ContenidoSobrante` |
| `TipoJson.JsonLogico`, `TipoJson.Nulo` | `CodigoErrorJson.EscapeInvalido`, `CodigoErrorJson.ClaveDuplicada`, `CodigoErrorJson.ProfundidadExcedida` |

::: limite
- La profundidad de anidación está limitada por el anfitrión, 64 por omisión: superarla es `ProfundidadExcedida`.
- Las claves repetidas son `ClaveDuplicada`.
- No hay igualdad entre valores JSON: se comparan sus textos.
:::

::: resumen
- `AnalizarJson` devuelve un valor o un error con posición.
- `Campo`, `Elemento` y `Como…` devuelven `Opcional`.
- `TextoJson` escribe JSON compacto que se puede volver a leer.
:::

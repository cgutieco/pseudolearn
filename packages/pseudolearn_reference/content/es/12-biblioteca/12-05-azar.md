::: frase
El azar de PseudoLearn sale de una fuente con **semilla**: con la misma semilla, el programa saca siempre los mismos números.
:::

## Cómo funciona {#funciona}

| Función | Devuelve |
|---|---|
| `Azar(n)` | un entero entre 0 y `n` - 1 |
| `Aleatorio(a, b)` | un entero entre `a` y `b`, ambos incluidos |
| `AzarReal()` | un real entre 0 y 1, sin llegar a 1 |

Las tres leen la misma fuente, y la fuente se inicia con una semilla que fija el anfitrión. Por eso una ejecución se puede repetir exactamente: en la app, en la terminal con `--semilla` y en este libro, que usa siempre la misma.

```figura id=semilla
pie: Con la misma semilla, dos ejecuciones sacan la misma secuencia. Con otra semilla, la secuencia cambia.
```

```programa id=dados titulo="Tres dados" ejecutar
Algoritmo Dados
  Escribir Azar(6) + 1, " ", Azar(6) + 1, " ", Azar(6) + 1;
  Escribir Aleatorio(10, 20), " ", AzarReal() < 1.0;
FinAlgoritmo
```

```salida
1 1 6
15 Verdadero
```

::: limite
`Azar(n)` exige `n` mayor que cero (`invalidRandomBound`) y `Aleatorio(a, b)` exige `a` menor o igual que `b` (`invalidRandomRange`).
:::

::: resumen
- `Azar`, `Aleatorio` y `AzarReal` comparten una fuente con semilla.
- La misma semilla da la misma secuencia.
- Los límites inválidos detienen el programa.
:::

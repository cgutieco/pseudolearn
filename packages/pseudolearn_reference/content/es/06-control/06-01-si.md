::: frase
`Si` hace una pregunta cuya respuesta solo puede ser `Verdadero` o `Falso`, y según la respuesta ejecuta un camino u otro. Nunca los dos.
:::

## Cómo se escribe {#escribe}

```forma
Si «condición» Entonces
  «instrucciones si es verdadera»
⟦Sino
  «instrucciones si es falsa»⟧
FinSi
```

```railes produccion=conditional
```

::: partes
- `Si` abre la decisión.
- «condición» es cualquier expresión cuyo resultado sea un `Logico`: una comparación como `edad >= 18`, una variable lógica o una combinación con `Y`, `O` y `NO`.
- `Entonces` separa la pregunta de lo que se hace. Es obligatoria siempre.
- «instrucciones» son cero o más sentencias. Un cuerpo vacío es válido.
- `Sino` es opcional. Introduce lo que se hace cuando la condición es falsa. Si no está, es como si su cuerpo estuviera vacío.
- `FinSi` cierra la decisión. Después de él, el programa sigue igual sea cual sea el camino elegido.
:::

## Cómo funciona {#funciona}

Sin `Sino`, `Si` es un desvío opcional. Si la respuesta es `Verdadero`, se hace algo más; si es `Falso`, no se hace nada y el programa sigue.

```programa id=paraguas titulo="¿Llevo paraguas?" ejecutar
Proceso Paraguas
  Definir llueve Como Logico <- Verdadero;
  Si llueve Entonces
    Escribir "Llevo el paraguas";
  FinSi
  Escribir "Salgo de casa";
FinProceso
```

```salida
Llevo el paraguas
Salgo de casa
```

Con `Sino` hay dos caminos y se recorre **exactamente uno**. Avanza paso a paso por la figura para ver qué hace el motor con este programa.

```programa id=montana titulo="¿Puedo subir a la montaña rusa?" ejecutar
Proceso Montana
  Definir estatura Como Entero <- 128;
  Si estatura >= 120 Entonces
    Escribir "Puedes subir a la montaña rusa";
  Sino
    Escribir "Todavía no: vuelve el año que viene";
  FinSi
FinProceso
```

```salida
Puedes subir a la montaña rusa
```

```figura id=si-ordinograma
pie: Un `Si` recorrido paso a paso. El rombo es la pregunta; de él salen dos flechas y solo una se recorre.
paso: Se ejecuta `Definir estatura Como Entero <- 128;`. La variable aparece en la memoria con el valor 128.
paso: El motor llega al `Si` y **evalúa la condición una sola vez**: `128 >= 120` da `Verdadero`.
paso: Como la respuesta es `Verdadero`, sigue por la rama de `Entonces` y ejecuta su `Escribir`.
paso: La rama `Sino` no se ejecuta: no se evalúa, no escribe nada y no cambia la memoria.
paso: En `FinSi` los dos caminos se juntan. No queda nada más, así que el programa termina.
panel Memoria 1: `estatura` = 128
panel Memoria 2: `128 >= 120` → `Verdadero`
panel Salida 3: Puedes subir a la montaña rusa
panel Traza 2: decisión · rama afirmativa
```

::: analogia
Un `Si` es como una bifurcación en un sendero con un cartel que hace una pregunta. Solo puedes tomar un camino, y más adelante los dos se juntan en `FinSi`. La analogía deja de valer en un punto: aquí no puedes volver atrás a probar el otro camino. Para repetir hace falta un bucle.
:::

## Más de dos caminos {#varias}

PseudoLearn no tiene una palabra especial para «si no, si…». Cuando hay más de dos casos, se pone un `Si` dentro del `Sino` de otro, y cada uno lleva su propio `FinSi`. Así cada decisión tiene siempre exactamente dos salidas.

```programa id=semaforo titulo="El semáforo de las notas" ejecutar
Proceso Semaforo
  Definir nota Como Entero <- 7;
  Si nota >= 9 Entonces
    Escribir "Excelente";
  Sino
    Si nota >= 6 Entonces
      Escribir "Aprobado";
    Sino
      Escribir "A repasar";
    FinSi
  FinSi
FinProceso
```

```salida
Aprobado
```

Las preguntas se hacen en orden y la primera que responde `Verdadero` gana. Por eso el orden importa: si se preguntara primero `nota >= 6`, un 10 también diría «Aprobado». Cuando los casos son valores concretos y no rangos, [`Segun`](#control.segun) se lee mejor.

## Condiciones compuestas {#compuestas}

Una condición puede juntar varias preguntas con `Y`, `O` y `NO`. El motor las evalúa **de izquierda a derecha y se detiene en cuanto sabe la respuesta**. Con `Y`, si la parte izquierda es `Falso`, la derecha ni se mira. Eso permite proteger una operación peligrosa.

```programa id=corto titulo="Dividir solo si se puede" ejecutar
Proceso Corto
  Definir divisor Como Entero <- 0;
  Si divisor <> 0 Y 10 / divisor > 1 Entonces
    Escribir "Grande";
  Sino
    Escribir "No se puede dividir";
  FinSi
FinProceso
```

```salida
No se puede dividir
```

Como `divisor <> 0` es `Falso`, la división `10 / divisor` nunca se calcula y el programa no se detiene por dividir entre cero.

::: errores
El motor exige que la condición sea un `Logico`. Un número no vale como pregunta:

```programa id=error-numero titulo="Una condición que no es lógica" ejecutar
Proceso ErrorNumero
  Definir edad Como Entero <- 12;
  Si edad Entonces
    Escribir "Hola";
  FinSi
FinProceso
```

```diagnosticos
nonBooleanCondition
```

Para arreglarlo, escribe la pregunta completa: `edad > 10`.

Olvidar `Entonces` también se detecta antes de ejecutar:

```programa id=error-entonces titulo="Falta Entonces" ejecutar
Proceso ErrorEntonces
  Definir edad Como Entero <- 12;
  Si edad > 10
    Escribir "Hola";
  FinSi
FinProceso
```

```diagnosticos
expectedThenKeyword
```

Y un `Si` sin su `FinSi` deja la decisión abierta:

```programa id=error-cierre titulo="Falta FinSi" ejecutar
Proceso ErrorCierre
  Definir edad Como Entero <- 12;
  Si edad > 10 Entonces
    Escribir "Hola";
FinProceso
```

```diagnosticos
unclosedIfStatement
```
:::

::: por-dentro
El motor traduce cada `Si` a bloques de la representación intermedia. Una instrucción `branch` elige entre dos bloques según un valor lógico. Fíjate en cómo el cortocircuito de `Y` aparece como un salto: si `divisor <> 0` es falso, se salta directamente a un bloque que vale `false` sin calcular la división.

```ri programa=corto
```

La traza registra la decisión con su rama:

```traza programa=montana
```
:::

::: docentes
La confusión más frecuente es creer que se ejecutan las dos ramas, o que `Sino` es obligatorio. Pide a la clase que prediga la salida de `semaforo` con notas 5, 6, 9 y 10 antes de ejecutarlo. Otra confusión habitual es escribir `Si nota >= 6 Y nota < 9` cuando el `Sino` ya garantiza que `nota < 9`.
:::

::: resumen
- `Si` pregunta algo que solo puede responderse con `Verdadero` o `Falso`.
- Se ejecuta exactamente un camino; `Sino` es opcional.
- `Entonces` y `FinSi` son obligatorios.
- Para más de dos casos se anidan decisiones; gana la primera pregunta verdadera.
- `Y` y `O` se detienen en cuanto conocen la respuesta.
:::

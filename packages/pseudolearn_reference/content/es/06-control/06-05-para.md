::: frase
`Para` cuenta de un número a otro y ejecuta el cuerpo una vez por cada valor, con una variable de control que avanza sola.
:::

## Cómo se escribe {#escribe}

```forma
Para «control» <- «inicial» Hasta «final» ⟦Con Paso «paso»⟧ Hacer
  «instrucciones»
FinPara
```

```railes produccion=forLoop
```

::: partes
- `Para` abre el bucle y declara la variable «control», de tipo `Entero`. No hace falta definirla antes.
- «inicial», «final» y «paso» son expresiones enteras.
- `Con Paso` es opcional. Sin él, el paso es 1.
- `Hacer` separa la cabecera del cuerpo.
- `FinPara` cierra el bucle.
:::

## Cómo funciona {#funciona}

Antes de la primera vuelta se calculan, **una sola vez y en este orden**, el inicial, el final y el paso. Después, en cada vuelta:

1. Se comprueba si el control ya pasó del final. El final está **incluido**.
2. Si no, se ejecuta el cuerpo.
3. Se suma el paso al control.

```programa id=tabla-siete titulo="La tabla del 7" ejecutar
Proceso Tabla
  Para i <- 1 Hasta 5 Hacer
    Escribir "7 x ", i, " = ", 7 * i;
  FinPara
FinProceso
```

```salida
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
```

```figura id=para-contador
pie: El control recorre los valores del inicial al final, ambos incluidos. Cuando se pasa del final, el bucle termina.
paso: Se calculan 1, 5 y el paso 1. El control empieza en 1.
paso: Cada vuelta escribe una línea y suma el paso: 2, 3, 4…
paso: Con el control en 5 todavía se entra: el final está incluido.
paso: El control llega a 6, que ya pasó del final. El bucle termina.
```

La dirección depende **solo del signo del paso**. Con paso negativo se cuenta hacia atrás. Si el inicial ya está más allá del final, el cuerpo no se ejecuta:

```programa id=pasos titulo="Pasos negativos y bucles vacíos" ejecutar
Proceso Pasos
  Para i <- 10 Hasta 0 Con Paso -5 Hacer
    Escribir i, " " Sin Saltar;
  FinPara
  Escribir "";
  Para i <- 5 Hasta 1 Hacer
    Escribir "nunca";
  FinPara
  Escribir "fin";
FinProceso
```

```salida
10 5 0 
fin
```

La variable de control vive solo dentro del bucle. Al terminar, deja de existir.

::: limite
- Un paso cero no ejecuta el cuerpo y detiene el programa con `zeroStepInCountedLoop`.
- El incremento usa aritmética entera comprobada, también tras la última vuelta: contar hasta el entero más grande desborda.
:::

::: errores
El control lo mueve el bucle, no el cuerpo:

```programa id=tocar-control titulo="Cambiar el control dentro del cuerpo" ejecutar
Proceso Tocar
  Para i <- 1 Hasta 3 Hacer
    i <- i + 1;
  FinPara
FinProceso
```

```diagnosticos
controlVariableModified
```

```programa id=paso-cero titulo="Un paso cero" ejecutar termina=failed
Proceso Cero
  Para i <- 1 Hasta 3 Con Paso 0 Hacer
    Escribir i;
  FinPara
FinProceso
```

```diagnosticos
zeroStepInCountedLoop
```
:::

::: por-dentro
El final y el paso se guardan en temporales antes de empezar. Por eso cambiar dentro del cuerpo una variable usada en la cabecera no altera las vueltas.

```ri programa=tabla-siete
```
:::

::: docentes
Pide predecir cuántas veces se ejecuta `Para i <- 0 Hasta 10 Con Paso 3`. La respuesta, 4 (0, 3, 6, 9), obliga a pensar que el final se incluye solo si se alcanza.
:::

::: resumen
- `Para` declara su control y lo mueve solo.
- Inicial, final y paso se calculan una vez.
- El final está incluido; el signo del paso da la dirección.
- El paso cero es un fallo; tocar el control, un error.
:::

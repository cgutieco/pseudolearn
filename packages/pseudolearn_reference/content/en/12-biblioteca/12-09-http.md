::: frase
With the network capability, a program builds an HTTP request, sends it and receives a response with its status, headers and body.
:::

## How it works {#funciona}

1. `requestNetwork()` gives a `NetworkCap`.
2. `HttpRequest(method, url)` creates a request with an `HttpMethod`: `GET`, `HEAD`, `POST`, `PUT`, `PATCH` or `DELETE`. Requests are immutable: `withHeader`, `withTextBody` or `withTimeout` return a new request.
3. `network.send(request)` returns `Result<HttpResponse, IoError>`.

```figura id=http-ida-vuelta
pie: The request goes out through the network capability and a response comes back. A 404 or a 500 are responses, not errors: only transport failures arrive as `IoError`.
```


A response with a status from 100 to 599 is always `Success`; `isSuccess()` says whether it is between 200 and 299. Methods that can modify the server —`POST`, `PUT`, `PATCH`, `DELETE`— can end up in an **uncertain** state if the connection drops half-way: the program cannot know whether the change happened.

::: limite
- Only `http` or `https` URLs with an ASCII host and no credentials are allowed.
- Redirects are not followed on their own: `redirected` builds the next request.
- Sizes and deadlines are limited by the host; `withResponseLimit` and `withTimeout` can only reduce them.
:::

::: resumen
- `requestNetwork`, `HttpRequest` and `send`: capability, request and response.
- HTTP statuses are responses; network failures are `IoError`.
- Requests are immutable and the limits belong to the host.
:::

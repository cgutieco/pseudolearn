::: frase
PseudoLearn's randomness comes from a source with a **seed**: with the same seed, the program always draws the same numbers.
:::

## How it works {#funciona}

| Function | Returns |
|---|---|
| `random(n)` | an integer between 0 and `n` - 1 |
| `randomBetween(a, b)` | an integer between `a` and `b`, both included |
| `randomReal()` | a real between 0 and 1, never reaching 1 |

All three read the same source, and the source starts from a seed set by the host. That is why a run can be repeated exactly: in the app, in the terminal with `--semilla` and in this book, which always uses the same one.

```figura id=semilla
pie: With the same seed, two runs draw the same sequence. With another seed, the sequence changes.
```

::: limite
`random(n)` requires `n` greater than zero (`invalidRandomBound`) and `randomBetween(a, b)` requires `a` less than or equal to `b` (`invalidRandomRange`).
:::

::: resumen
- `random`, `randomBetween` and `randomReal` share a seeded source.
- The same seed gives the same sequence.
- Invalid bounds stop the program.
:::

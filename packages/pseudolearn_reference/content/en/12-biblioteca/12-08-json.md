::: frase
`parseJson` turns a JSON text into a value you can walk through, and `jsonText` goes the other way.
:::

## How it works {#funciona}

`parseJson(text)` returns a `Result`: `Success` with a `JsonValue`, or `Error` with a `JsonError` saying what failed and where. On a `JsonValue` you can ask:

| Operation | Returns |
|---|---|
| `v.kind()` | what kind of value it is: object, array, text, number, boolean or null |
| `v.field(key)` | `Something(value)` or `Nothing` |
| `v.element(i)` | `Something(value)` or `Nothing`, with indices from zero |
| `v.keys()`, `v.length()` | the keys in their original order; how many elements |
| `asInteger`, `asReal`, `asText`, `asBoolean` | `Something` if the value is of that type |

`jsonText` writes compact JSON, keeps the order of keys and the original text of numbers. Parsing what it writes gives back the same value.

Parsing is **strict**: no comments, no trailing commas, no repeated keys. The error gives the line and column where it was detected:


The values of `JsonKind` and `JsonErrorCode` are these:

| `JsonKind` | `JsonErrorCode` |
|---|---|
| `JsonKind.Object`, `JsonKind.Array` | `JsonErrorCode.InvalidSyntax` |
| `JsonKind.JsonStringKind`, `JsonKind.JsonNumber` | `JsonErrorCode.UnexpectedEnd`, `JsonErrorCode.TrailingContent` |
| `JsonKind.JsonBoolean`, `JsonKind.Null` | `JsonErrorCode.InvalidEscape`, `JsonErrorCode.DuplicateKey`, `JsonErrorCode.DepthExceeded` |

::: limite
- Nesting depth is limited by the host, 64 by default: exceeding it is `ProfundidadExcedida`.
- Repeated keys are `ClaveDuplicada`.
- There is no equality between JSON values: compare their texts.
:::

::: resumen
- `parseJson` returns a value or an error with a position.
- `field`, `element` and `as…` return `Optional`.
- `jsonText` writes compact JSON that can be read back.
:::

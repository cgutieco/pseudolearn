::: frase
`For` counts from one number to another and runs the body once for each value, with a control variable that moves by itself.
:::

## How to write it {#escribe}

```forma
```

::: partes
- `For` opens the loop and declares the «control» variable, of type `Integer`. It does not need to be defined first.
- «initial», «final» and «step» are integer expressions.
- `With Step` is optional. Without it, the step is 1.
- `Do` separates the header from the body.
- `EndFor` closes the loop.
:::

## How it works {#funciona}

Before the first round, the initial value, the final value and the step are computed **only once and in that order**. Then, on every round:

1. It checks whether the control has gone past the final value. The final value is **included**.
2. If not, the body runs.
3. The step is added to the control.

```figura id=para-contador
pie: The control walks the values from the initial one to the final one, both included. When it goes past the final value, the loop ends.
paso: 1, 5 and the step 1 are computed. The control starts at 1.
paso: Every round writes a line and adds the step: 2, 3, 4…
paso: With the control at 5 the body still runs: the final value is included.
paso: The control reaches 6, which is past the final value. The loop ends.
```

The direction depends **only on the sign of the step**. With a negative step it counts backwards. If the initial value is already past the final one, the body does not run:

```programa id=pasos titulo="Negative steps and empty loops"
```

The control variable lives only inside the loop. When it ends, it stops existing.

::: limite
- A zero step does not run the body and stops the program with `zeroStepInCountedLoop`.
- The increment uses checked integer arithmetic, also after the last round: counting up to the largest integer overflows.
:::

::: errores
The loop moves the control, not the body:

:::

::: por-dentro
The final value and the step are kept in temporaries before starting. That is why changing, inside the body, a variable used in the header does not alter the rounds.

:::

::: nota
Predict how many times `For i <- 0 To 10 With Step 3` runs. The answer, 4 (0, 3, 6, 9), shows that the final value is only included if it is reached.
:::

::: resumen
- `For` declares its control and moves it by itself.
- Initial, final and step are computed once.
- The final value is included; the sign of the step gives the direction.
- A zero step is a failure; touching the control, an error.
:::

::: frase
`If` asks a question whose answer can only be `True` or `False`, and runs one path or the other depending on the answer. Never both.
:::

## How to write it {#escribe}

```forma
```

```railes produccion=conditional
```

::: partes
- `If` opens the decision.
- «condition» is any expression whose result is a `Boolean`: a comparison such as `age >= 18`, a boolean variable or a combination with `And`, `Or` and `Not`.
- `Then` separates the question from what is done. It is always required.
- «statements» are zero or more statements. An empty body is valid.
- `Else` is optional. It introduces what is done when the condition is false. Without it, it is as if its body were empty.
- `EndIf` closes the decision. After it, the program continues the same way whichever path was taken.
:::

## How it works {#funciona}

Without `Else`, `If` is an optional detour. If the answer is `True`, something extra is done; if it is `False`, nothing happens and the program carries on.

```programa id=paraguas titulo="Do I take an umbrella?"
```

With `Else` there are two paths and **exactly one** is taken. Step through the figure to see what the engine does with this program.

```programa id=montana titulo="Can I ride the roller coaster?"
```

```figura id=si-ordinograma
pie: An `If` walked through step by step. The diamond is the question; two arrows leave it and only one is followed.
paso: `Define estatura As Integer <- 128;` runs. The variable appears in memory with the value 128.
paso: The engine reaches the `If` and **evaluates the condition only once**: `128 >= 120` gives `True`.
paso: Since the answer is `True`, it follows the `Then` branch and runs its `Write`.
paso: The `Else` branch is not run: it is not evaluated, writes nothing and does not change memory.
paso: At `EndIf` both paths join. Nothing else remains, so the program ends.
panel Memory 1: `estatura` = 128
panel Memory 2: `128 >= 120` → `True`
panel Output 3: Puedes subir a la montaña rusa
panel Trace 2: decision · true branch
```

::: analogia
An `If` is like a fork in a trail with a sign that asks a question. You can only take one path, and further on both join again at `EndIf`. The analogy stops working at one point: here you cannot go back and try the other path. Repeating needs a loop.
:::

## More than two paths {#varias}

PseudoLearn has no special word for "else if". When there are more than two cases, an `If` goes inside the `Else` of another, and each has its own `EndIf`. That way every decision always has exactly two exits.

```programa id=semaforo titulo="The grade traffic light"
```

The questions are asked in order and the first one that answers `True` wins. That is why order matters: if `nota >= 6` were asked first, a 10 would also say "Aprobado". When the cases are concrete values rather than ranges, [Switch](#control.segun) reads better.

## Compound conditions {#compuestas}

A condition can combine several questions with `And`, `Or` and `Not`. The engine evaluates them **from left to right and stops as soon as it knows the answer**. With `And`, if the left part is `False`, the right part is never looked at. That lets you protect a dangerous operation.

```programa id=corto titulo="Divide only when possible"
```

Since `divisor <> 0` is `False`, the division `10 / divisor` is never computed and the program does not stop for dividing by zero.

::: errores
The engine requires the condition to be a `Boolean`. A number does not work as a question:

```programa id=error-numero titulo="A condition that is not boolean"
```

To fix it, write the full question: `edad > 10`.

Forgetting `Then` is also detected before running:

```programa id=error-entonces titulo="Then is missing"
```

And an `If` without its `EndIf` leaves the decision open:

```programa id=error-cierre titulo="EndIf is missing"
```
:::

::: por-dentro
The engine turns every `If` into blocks of the intermediate representation. A `branch` instruction chooses between two blocks according to a boolean value. Notice how the short circuit of `And` shows up as a jump: if `divisor <> 0` is false, it jumps straight to a block holding `false` without computing the division.

```ri programa=corto
```

The trace records the decision with its branch:

```traza programa=montana
```
:::

::: nota
The most common confusion is believing that both branches run, or that `Else` is required. Predict the output of `semaforo` with grades 5, 6, 9 and 10 before running it. Another frequent confusion is writing `If nota >= 6 And nota < 9` when the `Else` already guarantees that `nota < 9`.
:::

::: resumen
- `If` asks something that can only be answered with `True` or `False`.
- Exactly one path runs; `Else` is optional.
- `Then` and `EndIf` are required.
- For more than two cases decisions are nested; the first true question wins.
- `And` and `Or` stop as soon as they know the answer.
:::

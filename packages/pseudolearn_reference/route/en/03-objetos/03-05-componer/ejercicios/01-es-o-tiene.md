titulo: Is it or has it?
---

::: enunciado
Place each pair according to whether the first is a particular case of the second, or the first has the second.
:::

```categorias
- The first is a particular case of the second
- The first has the second
```

```elementos
- A cashier and a person | The first is a particular case of the second
- A circle and a figure | The first is a particular case of the second
- A product and its expiry date | The first has the second
- An order and its products | The first has the second
```

::: explicacion
A cashier is a person, and a circle is a figure: that is where inheriting fits. A product is not a date, and an order is not a product: it holds them inside, and that is where composing fits.
:::

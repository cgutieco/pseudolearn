titulo: Which of the three?
---

::: enunciado
Place each job in the way of walking that fits it.
:::

```categorias
- Change each element
- Keep some
- Gather all into a value
```

```elementos
- The prices with VAT. | Change each element
- The names in capitals. | Change each element
- Only the pupils who passed. | Keep some
- The products without stock. | Keep some
- The total of sales. | Gather all into a value
- The highest mark. | Gather all into a value
```

::: explicacion
Changing each element is mapping: the result has the same length. Keeping some is filtering: the result can be shorter. Gathering all into a value is reducing.
:::

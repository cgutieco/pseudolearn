::: enunciado
These are the steps of the report plan, mixed up. Put them in order.
:::

```pasos
- Read the sales until 0 and keep them in a list.
- Compute the amount of each sale.
- Add up the amounts for the total.
- Compute the total with discount.
- Keep the amounts over 5 pesos and count them.
- Count the units of each product and choose the star.
- Show the four lines of the report.
```

::: explicacion
The edge reads at the start and shows at the end; in the middle, each step is a function that uses what the previous step computed.
:::

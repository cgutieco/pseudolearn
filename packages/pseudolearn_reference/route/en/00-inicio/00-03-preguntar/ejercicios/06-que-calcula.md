::: enunciado
Choose the sentence that best explains what this program solves.
:::

```programa rol=objeto id=misterio
```

```opciones
- [ ] It multiplies two numbers. | It describes how it does it, not what it solves.
- [x] It computes the area of a rectangle from its length and its width. | It talks about the problem and uses the names of the boxes: `largo` is length and `ancho` is width.
- [ ] It adds two numbers. | It is false: the program multiplies.
```

::: explicacion
The names `largo` and `ancho` tell what problem the program solves. A good explanation talks about that, not about the operation.
:::

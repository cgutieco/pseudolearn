::: enunciado
Place each failure in the kind it belongs to.
:::

```categorias
- When compiling
- When running
- Logic
```

```elementos
- The engine marks line 4 before starting. | When compiling
- Some quotes are not closed. | When compiling
- The program stops when dividing. | When running
- It shows 3 when it should show 33. | Logic
- It computes the average with Ana's mark instead of Beto's. | Logic
```

::: explicacion
If the program never gets to start, the error is a compile error. If it starts and stops, it is a runtime error. If it finishes with a wrong result, it is a logic error: nobody but you will notice.
:::

::: enunciado
Which name suits the box that holds how many slices a pizza has?
:::

```opciones
- [ ] `p` | It is short, but it does not say what it holds: slices, people or pizzas?
- [ ] `x` | It says nothing about the problem.
- [x] `slicesPerPizza` | It reads by itself: slices per pizza. Anyone knows what the box holds.
- [ ] `numero` | Every box in the party holds numbers.
```

::: explicacion
A box's name is for the people who read the program. The computer accepts any name; your classmates, and you in a week, need one that says what it holds.
:::

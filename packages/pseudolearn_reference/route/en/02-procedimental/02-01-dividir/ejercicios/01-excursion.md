::: enunciado
Organising the class trip can be split into three smaller problems: transport, food and permissions. Place each job in its own.
:::

```categorias
- Transport
- Food
- Permissions
```

```elementos
- Hire the bus. | Transport
- Set the departure time. | Transport
- Buy water. | Food
- Make the sandwiches. | Food
- Collect the signed permission slips. | Permissions
- Tell the families. | Permissions
```

::: explicacion
Each branch groups jobs that can be solved without thinking about the others: whoever handles transport does not need to know what goes in each sandwich.
:::

titulo: Which shape suits it?
---

::: enunciado
Place each set of kiosk data in the shape that suits it best.
:::

```categorias
- Record
- Enumeration
- Vector
- Dictionary
- Array
```

```elementos
- The name, the price and the stock of a product. | Record
- The days of the week. | Enumeration
- The day's sales, which keep arriving without knowing how many there will be. | Vector
- The price of each product, looked up by its name. | Dictionary
- The seven temperatures of a week. | Array
```

::: explicacion
Different values of one thing go in a record; a closed list of values, in an enumeration; data that grows, in a vector; data looked up by something, in a dictionary; a fixed amount of values of the same type, in an array.
:::

::: enunciado
Estos son los pasos del plan de la caja, mezclados. Ordénalos.
:::

```pasos
- Preparar los nombres, los precios y las unidades vendidas de cada producto.
- Leer el primer código.
- Mientras el código no sea 0: validarlo, leer la cantidad, escribir la línea, sumar al total y a las unidades, y leer el código siguiente.
- Calcular el total con descuento.
- Buscar el producto más vendido.
- Escribir el cierre del ticket.
```

::: explicacion
Los datos fijos se preparan antes de leer nada. El primer código se lee antes del bucle para que la pregunta tenga algo que mirar. El descuento y el más vendido se calculan cuando ya no quedan ventas.
:::

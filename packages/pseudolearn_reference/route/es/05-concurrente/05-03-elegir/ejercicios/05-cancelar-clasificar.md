titulo: ¿Cortar o esperar?
---

::: enunciado
Ubica cada situación: ¿conviene cortar lo que falta, o hay que esperar a todos?
:::

```categorias
- Conviene cortar
- Hay que esperar
```

```elementos
- Buscar un libro en tres bibliotecas, y ya apareció en una. | Conviene cortar
- Sumar las ventas de tres cajas. | Hay que esperar
- Pedir un taxi a dos empresas, y ya llegó uno. | Conviene cortar
- Cocinar los tres platos de una bandeja. | Hay que esperar
```

::: explicacion
Se corta cuando una sola respuesta alcanza. Se espera cuando el resultado necesita a todos, como una suma o una bandeja completa.
:::

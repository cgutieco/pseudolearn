::: enunciado
¿Por qué un programa real suele mezclar las tres formas de pensar?
:::

```opciones
- [x] Porque cada parte del programa espera un tipo de cambio distinto. | Los cálculos crecen con operaciones nuevas, las cosas con estado crecen con tipos nuevos, y el borde es corto.
- [ ] Porque así es más rápido. | La velocidad no decide la forma de pensar.
- [ ] Porque ninguna sirve para nada sola. | Cada una sirve sola; mezclarlas aprovecha lo que facilita cada una.
```

::: explicacion
Un kiosco real tiene cálculos, que conviene escribir como funciones puras; cosas con estado, como el inventario, que conviene escribir como objetos; y un borde que lee y muestra, que es imperativo y corto.
:::

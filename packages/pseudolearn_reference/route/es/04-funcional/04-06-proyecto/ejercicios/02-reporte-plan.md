::: enunciado
Estos son los pasos del plan del reporte, mezclados. Ordénalos.
:::

```pasos
- Leer las ventas hasta el 0 y guardarlas en una lista.
- Calcular el importe de cada venta.
- Sumar los importes para el total.
- Calcular el total con descuento.
- Quedarse con los importes de más de 5 pesos y contarlos.
- Contar las unidades de cada producto y elegir la estrella.
- Mostrar las cuatro líneas del reporte.
```

::: explicacion
El borde lee al principio y muestra al final; en el medio, cada paso es una función que usa lo que calculó el paso anterior.
:::

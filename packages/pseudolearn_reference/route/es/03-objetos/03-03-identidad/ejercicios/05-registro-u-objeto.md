::: enunciado
En el kiosco, varias pantallas muestran el mismo pedido mientras se arma, y todas tienen que verlo actualizado. ¿Conviene que cada pantalla tenga su propia copia del pedido, o que todas compartan el mismo?
:::

```opciones
- [x] Como objeto. | Todas las pantallas pueden tener una referencia al mismo pedido: lo que agrega una, lo ven las demás.
- [ ] Como registro. | Cada pantalla tendría su propia copia, y los cambios de una no llegarían a las otras.
- [ ] Da lo mismo. | Justo aquí no da lo mismo: compartir es lo que se busca.
```

::: explicacion
Un registro se copia al asignarlo; un objeto se comparte. Cuando varias partes del programa tienen que ver lo mismo, compartir es una ventaja.
:::

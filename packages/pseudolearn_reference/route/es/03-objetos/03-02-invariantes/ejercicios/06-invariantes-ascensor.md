::: enunciado
Ubica cada frase sobre un ascensor según tenga que ser cierta siempre, en todo momento, o no sea algo que el ascensor tenga que cuidar.
:::

```categorias
- Siempre cierto
- No es algo que cuidar
```

```elementos
- El piso está entre 0 y 10. | Siempre cierto
- Hay como máximo 8 personas adentro. | Siempre cierto
- La puerta no se abre mientras se mueve. | Siempre cierto
- Es de color gris. | No es algo que cuidar
```

::: explicacion
Un invariante es una regla que el objeto tiene que mantener ante cualquier pedido: el piso, la cantidad de personas y la puerta. El color es un dato, pero ningún método puede romperlo.
:::

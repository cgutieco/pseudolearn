::: enunciado
Alguien escribe «doce» donde se pide una edad. ¿Por qué es mejor responder «no es un número» que dejar que el programa se detenga?
:::

```opciones
- [x] Porque quien lo usa sabe qué corregir, y el programa puede seguir. | El motivo dice qué hacer, y nadie pierde lo que ya había cargado.
- [ ] Porque así el programa es más corto. | Avisar exige más líneas: un filtro y su motivo.
- [ ] Porque detenerse está prohibido en PseudoLearn. | Un programa puede detenerse; el punto es que un error esperable no debería hacerlo.
```

::: explicacion
Un error esperable, como un dato mal escrito, es parte del problema: el programa tiene que responderlo. Detenerse se reserva para lo que no se puede prever.
:::

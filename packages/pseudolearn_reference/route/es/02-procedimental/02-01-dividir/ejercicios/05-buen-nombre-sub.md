::: enunciado
¿Cómo conviene llamar a la pieza de programa que dice si un año es bisiesto?
:::

```opciones
- [ ] `Calcular` | No dice qué calcula: cualquier pieza calcula algo.
- [ ] `Bisiesto` | Nombra el tema, pero no dice qué responde.
- [x] `EsBisiesto` | Se lee como una pregunta: `EsBisiesto(2024)` responde sí o no.
- [ ] `Hacer` | No dice nada del problema.
```

::: explicacion
Un buen nombre dice qué hace o qué responde. Si la pieza responde sí o no, conviene que su nombre se lea como una pregunta.
:::

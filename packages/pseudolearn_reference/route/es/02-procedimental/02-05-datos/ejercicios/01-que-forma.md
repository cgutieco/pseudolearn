titulo: ¿Qué forma le queda?
---

::: enunciado
Ubica cada conjunto de datos del kiosco en la forma que mejor le queda.
:::

```categorias
- Registro
- Enumerado
- Vector
- Diccionario
- Arreglo
```

```elementos
- El nombre, el precio y el stock de un producto. | Registro
- Los días de la semana. | Enumerado
- Las ventas del día, que van llegando sin saber cuántas serán. | Vector
- El precio de cada producto, buscado por su nombre. | Diccionario
- Las siete temperaturas de una semana. | Arreglo
```

::: explicacion
Datos distintos de una misma cosa van en un registro; una lista cerrada de valores, en un enumerado; datos que crecen, en un vector; datos que se buscan por algo, en un diccionario; una cantidad fija de datos del mismo tipo, en un arreglo.
:::

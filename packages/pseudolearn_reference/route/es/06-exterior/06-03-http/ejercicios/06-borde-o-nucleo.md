::: enunciado
Ubica cada paso del precio de la fruta importada: ¿va en el núcleo que solo calcula, o en el borde que toca el mundo?
:::

```categorias
- Núcleo
- Borde
```

```elementos
- Pedir la capacidad de red. | Borde
- Calcular el precio en pesos. | Núcleo
- Leer el JSON de la respuesta. | Núcleo
- Escribir el precio. | Borde
```

::: explicacion
Analizar un texto que ya llegó es cálculo: recibe un texto y devuelve un valor. Pedir la red y escribir tocan el mundo.
:::

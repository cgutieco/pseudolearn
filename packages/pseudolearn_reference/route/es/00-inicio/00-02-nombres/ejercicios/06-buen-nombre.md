::: enunciado
¿Qué nombre conviene a la caja que guarda cuántas porciones trae una pizza?
:::

```opciones
- [ ] `p` | Es corto, pero no dice qué guarda: ¿porciones, personas o pizzas?
- [ ] `x` | No dice nada del problema.
- [x] `porcionesPorPizza` | Se lee solo: cualquiera sabe qué guarda la caja.
- [ ] `numero` | Todas las cajas de la fiesta guardan números.
```

::: explicacion
El nombre de una caja es para las personas que leen el programa. La computadora acepta cualquiera; tus compañeros, y tú dentro de una semana, necesitan uno que diga qué guarda.
:::
